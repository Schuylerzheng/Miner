# Miner

An Unreal Engine game

## Future

I don't know if I can keep contributing a lot in the future.
The idea of this project was to make the first open source gnu affero v3 game where people could look to get inspiration for their own projects.
I also wanted to make a fun game like minecraft to let people be creative and have fun.
Turns out world gen and multiplayer are hard to implement, so updates for simple features take ages because this is my first full game.
If this project is to continue, then more experienced people are going to have to contribute because I don't have a lot of time.

## Goals for the Project

* Have realistic movement
* Mostly realistic mechanics
* Fun game :)

## How to contribute

Go read contributing.md, and then make an issue with what you want changed. If you can, you should also make a pull request with a fix.
