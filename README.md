# Miner

An Unreal Engine game

## Future

I don't know if I can keep contributing a lot in the future.

The core ideas of this project were:

* Making it open source so it is easy for people to get inspired (like take code snippets) and be able to edit it if anything went wrong with the main project (corrupt org, etc)
* Realistic planet terrain
* Realistic building with phyhsics and gravity affecting them
* Good server multiplayer helpers (routing players over multiple servers closer to them, easy moderation, uncrackable seeds/anticheat, etc)
* Evolution with creatures adapting to their environment and starting already adapted so you can see what you did to your world
* Some redstone like creation, but you can just make circuts smaller and smaller with the right tools making big restone contraptions able to fit in spaces reasonably (also computers and networking?).

Future
