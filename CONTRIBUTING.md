# How to contribute

Here is a simple guide for a few steps to contribute. Thanks for contributing!

1. Read the [coding guidelines](https://github.com/MinerOrg/Miner/blob/master/docs/code-style.md)
2. Create an issue with what you want changed (or find an issue to work on)
3. Make changes in a fork
4. Make a pull request and I will look at it
